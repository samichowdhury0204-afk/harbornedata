# Harborne Growth Partner

Build a premium, one-page website for **Harborne Data**, a B2B outsourced sales company specialising in manufacturing.

I have provided the current Harborne Data logo as an asset.

IMPORTANT:

Use the existing Harborne Data logo and its existing geometric mark.

The logo consists of a distinctive geometric copper/bronze mark alongside the words:

harborne

data

The existing copper/bronze mark should become an important part of the site's visual identity.

However, DO NOT use the current black circular background from the logo as the website's primary visual treatment.

Instead, extract/use the logo cleanly against the new website palette.

==================================================

BRAND DIRECTION

==================================================

Harborne Data should feel like:

- a serious British B2B company, targetting UK and US manufacturers.

- a specialist manufacturing sales partner  - generating a cosnsitent flow of leads - RFQ's, and calls for enquiries.

- precise

- established

- commercially intelligent

- calm

- trustworthy

- premium

- understated

It should NOT feel like:

- an AI startup

- a SaaS company

- a marketing agency

- a generic lead-generation company

- a crypto/Web3 site

- a flashy sales funnel

- a "10x growth" agency

The website should make a manufacturing owner or MD think:

"These people understand how manufacturers sell."

"They aren't going to waste my time with rubbish leads."

"They'll handle the prospecting for me."

"I only need to get involved when there is a genuine opportunity."

"I could trust them with the front end of my sales process."

==================================================

CORE POSITIONING

==================================================

Harborne Data is an **outsourced lead generation team for manufacturers**.

We find relevant prospects, launch targetted campaigns on behalf of our client, and hand off qualified leads.

The website should NOT primarily sell "lead generation".

It should feel like:

**an outsourced growth partner.**, even though it's service is lead generation. 

The fundamental process is:

TARGET

→

ENGAGE

→

QUALIFY

→

HANDOFF

→

RFQ / CALL / CUSTOMER

The manufacturer should feel that Harborne Data effectively operates the front end of their sales process.

Core message:

**We find the right companies, start the conversation and hand qualified opportunities directly to your team. to deliver on**

==================================================

COLOUR PALETTE

==================================================

DO NOT use a black website.

Use a sophisticated warm industrial palette.

Primary background:

- warm ivory / off-white / very light stone

Suggested background:

#F5F2EC or similar

Primary text:

- very dark blue-black / charcoal

- approximately #102025

Secondary text:

- muted slate / grey

Accent:

- use the existing copper / bronze from the logo

The copper should be used sparingly for:

- buttons

- small highlights

- lines

- icons

- active states

- important words

- subtle animations

Do NOT turn the entire website copper.

The result should feel like:

**warm ivory + deep navy/charcoal + copper**

rather than:

**black + neon + gradients**

The existing copper logo should look excellent against the ivory background.

LOGO

==================================================

On the main website:

- preserve the copper/bronze mark

- preserve the typography of the logo

If necessary, create a clean transparent-background version of the logo for use on the site while keeping the mark and wordmark exactly the same.

The logo should appear refined and understated.

==================================================

TYPOGRAPHY

==================================================

Use a premium modern sans-serif.

Avoid excessively rounded startup fonts.

Headlines should be large, confident and editorial.

Body text should be highly readable.

Use small uppercase labels for sections.

For example:

01 / IDENTIFY

02 / ENGAGE

03 / QUALIFY

04 / HANDOFF

Occasionally use a restrained monospace font for technical metadata.

Do not overuse monospace.

==================================================

ANIMATION

==================================================

Beautiful animation is important.

But the animations should feel expensive and deliberate rather than flashy.

Use Framer Motion or an equivalent modern animation system.

Use:

- subtle fade/translate reveals

- staggered typography

- elegant line animations

- smooth card entrances

- subtle hover states

- animated process diagrams

- gentle movement of technical lines

- very subtle logo-related geometric animations

Avoid:

- bouncing

- excessive parallax

- spinning objects

- flashy transitions

- excessive text animation

- animations that slow down the site

Respect prefers-reduced-motion.

The animation should communicate precision and process.

COPY RULES

==================================================

This is extremely important.

The copy must NOT sound AI-generated.

Write like a real specialist B2B company.

Use:

- short sentences

- plain English

- confident statements

- specific language

- commercially relevant language

Avoid:

- corporate jargon

- unnecessary adjectives

- exaggerated promises

- fake authority

- excessive claims

- exclamation marks

- generic testimonials

- "revolutionary"

- "cutting edge"

- "AI-powered"

- "10x"

- "unlock"

- "supercharge"

- "game-changing"

- "seamless"

- "next-generation"

Do not mention AI unless it is genuinely relevant to a specific service.

The website should never feel like it is trying to convince the visitor that Harborne Data is futuristic.

It should convince them that Harborne Data is **competent**.

==================================================

After building the website, review it as if you are a UK manufacturing MD who has been approached by dozens of poor lead-generation companies.

The site should make them think:

"These people understand manufacturing."

"They understand the difference between a lead and an opportunity."

"They will handle the prospecting."

"I won't have to waste time sorting through rubbish."

"They only bring me in when there's something worth pursuing."

"I'd be comfortable having these people represent my business."

The final website should feel like:

**A serious specialist sales partner for manufacturing companies.**

Not:

**Another AI lead-generation agency.**

Do not add sections simply to make the website longer.

If a section does not improve trust, clarity or conversion, leave it out.

The design should feel **simple, expensive and deliberate**.
